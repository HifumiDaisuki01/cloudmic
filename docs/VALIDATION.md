# CloudMic Next 2.0 验证记录

## 自动验证范围

- 9 项桌面回归测试：队列顺序与去重、有界队列、取消合成、停止播放、过期消息跳过、合成失败恢复、下一句预取、输出失败不误报播放、断线后取消 writer 并重连。
- 2 项协议单元测试：配对码/凭据生成与消息格式限制。
- 16 项中转集成检查：健康接口、跨站拒绝、码格式、创建与配对、手机不能冒充电脑、认证、在线状态、文字转发、四阶段回执、停止、长度限制、畸形消息恢复、电脑离线、重连和撤销后拒绝配对。
- 实际 Cloudflare Worker 部署后的同一检查通过。测试环境一次“文字转发 + 四次状态回执”累计约 89ms；这不是国内网络、TTS 或手机到对方听见的延迟指标。
- 浏览器通过实际手机网页配对并发送中文，新版后台成功调用在线服务、解码音频及反馈状态。该检查用解码器替代物理声卡输出，不能冒充真实听音验收。
- 在线中文 MP3 在 24k / 44.1k / 48kHz 重采样后的时长一致（3.384 秒），避免旧版错误采样率导致变速。
- Windows 构建机启动独立打包 EXE，生成窗口截图与 JSON 报告。最终报告和截图随 Release 提供。

## 未以自动检查代替的项目

真实 Windows 电脑的 VB-CABLE 驱动安装、游戏内语音输入、蓝牙设备、真人音质试听、国内运营商网络与云桌面限制，需要目标设备实测。构建机没有可用音频输出端点，报告中的 `audio_devices: 0` 如实保留。

Azure Speech 接口已实现，但本次没有用户 Azure Speech 订阅密钥，未做付费云端调用验证。Windows 本地 SAPI 的语言和音质取决于系统语音包。

公共默认中转受 Cloudflare 免费配额与网络可达性限制；在线自然语音受第三方服务变化影响。不据此承诺固定延迟、无限免费容量或所有游戏兼容。
